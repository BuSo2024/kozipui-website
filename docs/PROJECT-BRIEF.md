# KoziPui Website Project Brief

## 1. Project Status
Status: Planning stage. No implementation yet.

Important rule:
Do not generate website code until the full visual direction, menu, sections, copy, language structure, and assets are approved.

## 2. Brand Overview
KoziPui is an embroidery and personalized textile brand.
The visual identity should feel warm, handmade, premium, friendly, and subtly Mediterranean-inspired.
The toucan logo is the main visual anchor.

## 3. Updated Color System

The previous warm cream dominant palette is rejected.
The new direction must use a background between white and baby blue.

The website should feel:
- airy
- premium
- handmade
- soft
- clean
- modern
- friendly

### Primary colors

Cloud White: #F8FBFF
Use as the main website background.
This is the dominant color.

Baby Blue Mist: #EAF3FB
Use as soft section background, cards, and gentle contrast areas.

Powder Blue: #D7E8F6
Use as secondary blue surface, subtle depth, supporting cards, and soft UI backgrounds.

Soft Charcoal: #2F2C2A
Use as the main text color.

Blue Slate: #6E8295
Use as secondary text, muted icons, supporting UI details.

KoziPui Orange: #F26A2E
Use as the primary brand accent, CTA buttons, active states, small highlights, and thread details.

Golden Ochre: #D99A3A
Use as a secondary warm accent, only in small details.

Olive Leaf: #7A7F5D
Use as a natural accent for botanical elements, embroidery leaves, and subtle decorative details.

Warm White: #FFFFFF
Use for cards, clean surfaces, inputs, and UI components.

### Suggested usage balance

55% Cloud White #F8FBFF  
20% Baby Blue Mist #EAF3FB  
10% Powder Blue #D7E8F6  
8% Soft Charcoal / Blue Slate #2F2C2A / #6E8295  
5% KoziPui Orange #F26A2E  
2% Golden Ochre / Olive Leaf #D99A3A / #7A7F5D

### Design rules

Use the blue-white palette as the base.
Do not use the old cream/ivory background as the dominant website background.
Orange must remain an accent, not a large background.
The website should look bright, premium, clean, airy, and soft.
Avoid beige-heavy, yellowish, dusty, or old-fashioned backgrounds.
Avoid corporate grey dominance.
Avoid childish baby-shop styling.
Avoid overloaded marketplace styling.

The logo colors must still be respected, but the website background should feel fresher and more premium through the white-to-baby-blue direction.

## Navigation and Information Architecture

Desktop top menu:
- Catalog
- Personalization
- About Us
- Contact

Gallery and Reviews must not appear in the top menu.
They will appear as sections on the Home page and as links in the footer.

Permanent header elements:
- TR/EN language switcher
- Cart icon

Mobile navigation:
The mobile version must include a fixed bottom navigation bar with exactly these items:
- Catalog
- Personalization
- Cart
- WhatsApp

Mobile header:
- Logo
- TR/EN language switcher
- Cart icon
- Hamburger menu if needed

Cart rule for Version 1:
The cart is not a payment checkout.
There is no online payment system in Version 1.
The cart should function as a quote/request basket.
The final action should guide the user toward WhatsApp contact or manual order confirmation.

Home page structure, not final but preferred direction:
1. Hero section with future native website animation
2. Catalog/category preview
3. Personalization process
4. Gallery section
5. Reviews section
6. About KoziPui section
7. Final contact CTA
8. Footer

Hero animation:
The Canva slideshow approach was rejected because it looked cheap and generic.

The hero animation should not be a simple video slideshow.

Preferred direction:
The hero animation should be created as a native website animation using HTML/CSS/JavaScript when implementation begins.

It should feel like a premium animated landing page, not like a video montage.

Animation structure:
- Cloud White (#F8FBFF) background with soft baby blue supporting surfaces
- large rounded hero card
- separate text block
- product image cards with rounded corners
- subtle overlapping cards
- slow fade and slide transitions
- soft parallax movement
- orange thread / embroidery line as a decorative accent
- no visible video player
- no full-screen image slideshow
- no cheap zoom/fade presentation style

The uploaded/generated embroidery images may be used as visual assets inside cards, but they must not simply be shown one after another full-screen.

The animation should be coded later as part of the website interface, not exported from Canva.

Do not implement yet.
The animation assets and behavior must be provided and approved before implementation is explicitly authorized.

Design reference direction:
Use the uploaded references only as inspiration for layout behavior and information display.
Do not copy any design literally.
Preferred direction:
- editorial boutique layout
- warm handmade premium feel
- clean commercial structure
- strong mobile usability
- large visual sections
- soft rounded cards
- clear CTA buttons
- elegant footer

Avoid:
- overloaded marketplace layout
- too many categories in the header
- discount-heavy e-commerce feeling
- generic template look
- cold corporate style

Important:
The project is still in planning stage.
Do not start website implementation until explicitly instructed.

## Personalization Page

The Personalization page must include a two-column structure on desktop and a stacked layout on mobile.

Main purpose:
Users must be able to personalize a product in two ways:
1. Simple text embroidery
2. Uploading their own design/logo

### Left column: Simple text embroidery

This area should allow the user to:
- choose a product type
- type a custom text
- choose a thread color
- see a live preview
- send the request via WhatsApp

Product options:
- Regular T-shirt
- Polo T-shirt
- Towel
- Tote bag

Preferred interaction:
The product selection should be visual, using selectable product cards or buttons, not just a dropdown.

Fields / elements:
- product selector
- preview area
- text input
- thread color picker
- WhatsApp CTA

### Right column: Upload your own design

This area should allow the user to:
- upload a file
- write a note
- submit the form
- send the file via WhatsApp

Fields / elements:
- file upload input
- textarea for notes
- submit button
- WhatsApp button

Suggested note placeholder:
“Your note (product, color, quantity, placement)”

### Visual style

This section should match the updated KoziPui palette with a light background between white and baby blue.
It should feel premium, airy, clean, and easy to use.

Avoid:
- heavy technical form styling
- cluttered layout
- marketplace feeling
- harsh borders

Preferred style:
- rounded cards
- subtle borders
- soft blue-white background
- orange accent only for primary actions or active selections
- clean preview area

Version 1 note:
The preview does not need to be highly advanced.
A simple elegant live preview that updates product, text, and thread color is enough for Version 1.
